# คู่มือการวาดเส้นทางเพิ่มเติม (Manual Links) สำหรับ WayFind

ไฟล์ `manual-links.geojson` ใช้สำหรับเติมเส้นทางเท้า ทางลัด หรือทางเข้าอาคารที่ยังไม่มีใน OpenStreetMap เพื่อให้ Graph ของระบบนำทางเชื่อมต่อสมบูรณ์ 100%

---

## 1. คุณสมบัติของ Feature ใน `manual-links.geojson`
ทุกเส้นทางต้องเป็น `LineString` ในรูปแบบ GeoJSON:
```json
{
  "type": "Feature",
  "properties": {
    "name": "ทางลัดลานอิฐหน้า RB5",
    "kind": "footway", // 'footway' | 'shortcut' | 'entrance'
    "note": "ทางเดินปูตัวหนอนเชื่อมระหว่างทางเท้าหลักกับบันไดอาคาร"
  },
  "geometry": {
    "type": "LineString",
    "coordinates": [
      [98.952575, 18.802162],
      [98.952480, 18.802020]
    ]
  }
}
```

---

## 2. วิธีวาดผ่าน geojson.io (แนะนำ - สะดวกที่สุด)
1. เปิดเว็บไซต์ [geojson.io](https://geojson.io)
2. ซูมเข้าไปยังพื้นที่มหาวิทยาลัยเชียงใหม่ (พิกัดประมาณ `18.801, 98.952`)
3. ใช้เครื่องมือ **Draw LineString** (ไอคอนเส้นเฉียง) คลิกจุดเริ่มต้นและจุดปลายทางตามแนวทางเดินจริง
4. ในแท็บ JSON ด้านขวา ให้เติม `properties` เช่น `name`, `kind` ('footway' หรือ 'shortcut'), `note`
5. คัดลอกเฉพาะก้อน `Feature` หรือทั้ง `FeatureCollection` มาวางใน `src/data/campus/manual-links.geojson`
6. ตอนคำนวณ Graph ระบบจะ snap ปลายเส้นเข้ากับโหนดทางเดิน OSM ที่ใกล้ที่สุดภายในระยะ 5 เมตรโดยอัตโนมัติ

---

## 3. วิธีวาดผ่าน Google My Maps และการตรวจสอบไฟล์ KML
1. สร้างแผนที่ใหม่ใน Google My Maps แล้วใช้เครื่องมือ "เพิ่มเส้นหรือเส้นทางเดิน"
2. วาดเส้นทางบนแผนที่ บันทึกชื่อ
3. กดเมนูตัวเลือกสามจุด (⋮) ข้างชื่อแผนที่ → เลือก **Export to KML/KMZ**
4. **ข้อควรระวังสำคัญมาก (วิธีเช็กว่า KML มีข้อมูลจริง ไม่ว่างเปล่า)**:
   - ตรวจดูว่าได้ติ๊กเลือกเลเยอร์ที่มีเส้นวาดอยู่จริง
   - เปิดไฟล์ `.kml` ด้วย Text Editor แล้วค้นหาคำว่า `<Placemark>` และ `<LineString>` หรือ `<coordinates>`
   - หากไฟล์มีเพียง `<Folder>` ว่างๆ แสดงว่าไม่มีเส้นทางบันทึกอยู่
   - แปลง KML เป็น GeoJSON ผ่านเครื่องมือ เช่น `togeojson` หรือ geojson.io ก่อนนำมาใส่ใน `manual-links.geojson`
